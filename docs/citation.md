# Citing WeaveMark

If WeaveMark helps your research, writing, or software work, cite it as
software. Add the version when citing a specific release.

## BibTeX

```bibtex
@misc{salem2026weavemark,
  author = {Salem, Paulo},
  title = {{WeaveMark}: A Specification Language for Readable, Reusable, and Composable Prompts},
  year = {2026},
  url = {https://github.com/paulosalem/weavemark},
  note = {Computer software}
}
```

## APA

Salem, P. (2026). *WeaveMark: A specification language for readable, reusable,
and composable prompts* [Computer software]. GitHub.
https://github.com/paulosalem/weavemark
